# Презентации к двум силлабусам METU

В папке предусмотрено **30 файлов PowerPoint**: 15 презентаций для осеннего и 15 для весеннего силлабуса. Ссылки в `index.html` уже используют оригинальные имена файлов из исходного архива `Силабус 1-2.zip`.

## Как добавить исходные файлы без скачивания нового архива

1. На своём компьютере найди исходный архив `Силабус 1-2.zip`, который отправлял в ChatGPT.
2. Распакуй его в отдельную папку.
3. На GitHub открой `presentations/` и выбери **Add file → Upload files**.
4. Перетащи все 30 файлов `.pptx` из распакованной папки в окно GitHub. Не загружай сам ZIP.
5. Нажми **Commit changes**. Если браузер не принимает все сразу, загружай по 5–10 файлов.

**Важно:** загружай PPTX прямо в папку `presentations` (не создавай внутри неё ещё одну папку). Имена файлов не меняй. Сайт проверяет наличие каждого файла автоматически и показывает кнопку «Презентация», когда файл доступен.
