# Презентации к двум силлабусам METU

В папке должны находиться **30 файлов PowerPoint**: по 15 недель для каждого силлабуса.

## Как добавить презентации

1. Скачайте приложенный к этому чату архив `presentations_for_github.zip`.
2. Распакуйте архив на компьютере.
3. Откройте папку `presentations` внутри архива.
4. В GitHub откройте эту папку репозитория и выберите **Add file → Upload files**.
5. Загрузите все 30 файлов из распакованной папки `presentations` и нажмите **Commit changes**. Если браузеру тяжело отправить всё сразу, загружайте тремя партиями по 10 файлов.

**Не загружайте сам ZIP-архив**: он больше стандартного лимита GitHub для одного файла. Загрузите именно 30 файлов `.pptx` из него.

Имена файлов менять нельзя: ссылки в `index.html` уже настроены на эти имена. Архив содержит переименованные копии исходных презентаций.
